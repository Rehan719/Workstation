# Contributing to Workstation

We love your input! We want to make contributing to the Workstation ecosystem as easy and transparent as possible.

## Pull Request Process

1. **Fork the repo** and create your branch from `main`.
2. **Standardize**: Ensure your changes align with the current **Sentient Civilization Epoch (v137.1)**.
3. **Test**: If you've added code, add tests (maintain ≥90% coverage).
4. **Document**: If you've changed APIs or introduced features, update the documentation following the **[Documentation Style Guide](docs/STYLE_GUIDE.md)**.
5. **Verify**: Run the pre-commit checks and ensure the full test suite passes.
6. **Submit**: Issue that pull request!

## Documentation Standards

All contributions to documentation must:
- Use **ATX headings**.
- Adhere to terminology (e.g., "VSB AI CEO").
- Use **Mermaid** for diagrams.
- Refer to the latest version (**v137.1**).

See the **[Full Style Guide](docs/STYLE_GUIDE.md)** for more details.

## Code of Conduct

We are committed to providing a friendly, safe, and welcoming environment for all. Please be kind and respectful. See our **[Code of Conduct](CODE_OF_CONDUCT.md)** for details.

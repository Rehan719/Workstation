# v190 API Contracts (Cognitive Convergence)

## 1. Extrospection (/api/v190/extrospection)
- `GET /signals`: Returns a feed of recent global signals and research trends.
- `GET /search`: Trigger an active extrospection query across integrated data sources.

## 2. Introspection (/api/v190/introspection)
- `GET /vitals`: Returns current system biochemical levels (Oxytocin, Serotonin, Dopamine) and health score.
- `GET /telemetry`: Detailed resource usage and anomaly reports.

## 3. Evolution (/api/v190/evolution)
- `GET /trajectories`: Visualizes current learning paths and knowledge graph depth.
- `GET /history`: Timeline of recent self-reconfigurations and genomic updates.

## 4. Governance (/api/v190/governance)
- `GET /constitution`: Returns searchable constitutional articles.
- `GET /compliance`: Real-time audit reports against Floor 20-55.

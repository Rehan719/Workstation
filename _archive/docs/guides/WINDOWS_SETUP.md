## 2. Setting Up Ollama 🧠

Once Ollama is installed, open your terminal (PowerShell or Command Prompt) and run:

```powershell
ollama pull llama3.2
```

This will download the default model used by the AI CEO. Ensure Ollama is running in the background.

## 4. One-Click Setup 🚀

We've provided a PowerShell setup script to automate the installation of dependencies:

```powershell
# You might need to allow script execution first:
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process

.\setup.ps1
```

This script will:
- Install **Poetry** (if missing).
- Set up the **Backend** environment and dependencies.
- Install **Web Frontend** dependencies.
- Install **Mobile App** dependencies.

## 5. Running the Application 🏃‍♂️

You will need three separate terminal windows in VS Code:

### Terminal 1: Backend
```powershell
cd agentic_core
poetry run uvicorn main:app --reload --port 8000
```
*Wait for the message: "Application startup complete."*

### Terminal 2: Web Frontend
```powershell
cd apps/web
npm run dev
```
*Open your browser to the URL provided (typically `http://localhost:5174`).*

### Terminal 3: Mobile App (Optional)
```powershell
cd apps/mobile
npx expo start
```
*Use the Expo Go app on your phone to scan the QR code.*

## 7. Troubleshooting ❓

- **Ollama Offline:** If the AI CEO says "Ollama Offline," ensure the Ollama application is running and you've pulled the `llama3.2` model.
- **Port Conflicts:** If a port is in use, use `Stop-Process -Id (Get-NetTCPConnection -LocalPort 8000).OwningProcess` in PowerShell to clear it.
- **Environment Variables:** If needed, create a `.env` file in the root directory based on `.env.template`.
- **WebSocket Issues:** If the browser console shows WebSocket errors, ensure the backend is running on port 8000. The Workstation v138.0 backend handles upgrades directly at `/api/v154/ws/streams`.

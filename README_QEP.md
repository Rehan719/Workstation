## Quick Start
To launch the standalone product:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/rehan719/workstation-v1.git
    cd workstation-v1
    ```

2.  **Run the standalone setup script:**
    ```bash
    ./setup_qep.sh
    ```

3.  **Access the Dashboard:**
    Open `http://localhost:5173` in your browser.

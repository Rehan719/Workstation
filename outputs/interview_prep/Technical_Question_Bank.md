# UKHSA Technical Question Bank

1. **How would you validate a new PCR assay for UKAS accreditation?**
   *   Focus on ISO 15189 clauses 5.5/5.6. Plan using FMEA, execute technical validation (LoD, specificity, precision), document via change control, and monitor via EQA/IQC.

2. **Describe your experience with ALCOA+ data integrity.**
   *   Implemented in LIMS redesign at Anthony Nolan: automated audit trails, electronic signatures, and immutable records.

3. **How do you handle assay discrepancies across multi-center studies?**
   *   Use fishbone diagrams, 5-Whys root cause analysis, and Delphi consensus building as demonstrated in the WHO International Standard projects.

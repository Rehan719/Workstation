# v139.0 Cognitive Architecture Map

## 1. Extrospection Engine
- **Source**: `agentic_core/synthesis/dual_mode_scraper.py`, `agentic_core/synthesis/uviap.py`
- **Capability**: Passive environmental monitoring, active scholarly search, and cross-platform signal ingestion.
- **Exposure**: Real-time "Global Signal" feed and research assistance.

## 2. Introspection & Homeostasis
- **Source**: `agentic_core/telemetry/`, `agentic_core/homeostasis/`, `agentic_core/pulse/`
- **Capability**: Monitoring of internal "biochemical" states (Oxytocin, Serotonin, Dopamine levels), system health, and resource efficiency.
- **Exposure**: "Self Vision" dashboard with vital sign visualizations.

## 3. Learning & Evolution Pipelines
- **Source**: `agentic_core/evolution/`, `agentic_core/knowledge/`, `agentic_core/genetics/`
- **Capability**: Epigenetic evolution, genomic network reconfiguration, and hierarchical knowledge synthesis (Merkle-DAG).
- **Exposure**: "Mind Forge" visualization of current learning trajectories and evolution history.

## 4. Operational Modes
- **Source**: `agentic_core/governance/`, `agentic_core/synthesis/reconfiguration/`
- **Capability**: Dynamic reconfiguration of agent roles and UI layouts based on the active mode (e.g., Strategic, Research, Defense).
- **Exposure**: Shell-level "Mode Switcher".

## 5. Constitutional Governance
- **Source**: `agentic_core/constitution/`, `agentic_core/compliance/`
- **Capability**: Real-time compliance monitoring and automated audit trail generation (Floor 20 Articles).
- **Exposure**: "Governance Console" with searchable articles and compliance reports.

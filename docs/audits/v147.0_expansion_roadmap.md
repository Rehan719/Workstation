## 1. Scalability Audit (1M Users / 10K Nodes)
- **Bottlenecks**: Single-region API handlers, non-sharded persistence for activity logs.
- **Solutions**:
  - Horizontal scaling for `v270` handlers.
  - Regional edge node clusters (Gossipsub optimized).
  - Sharded activity and preference storage.

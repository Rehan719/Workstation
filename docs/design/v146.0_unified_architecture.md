# v146.0 Unified Architecture & Information Hierarchy

## 1. The Singular Interface
- **Objective**: Dissolve the boundaries between "Federation Portal", "Cognitive Hub", and "Economic Wallet".
- **Concept**: A unified "Civilization Command Console" where every view is context-aware.

## 2. Redesigned Navigation Flow
- **Universal Sidebar**: Replaced "Federation Portal" and "Self Vision" with direct, categorized access to the civilization's facets:
  - **The Pulse** (Real-time vitals, news, global health)
  - **The Mind** (Extrospection, Introspection, Learning)
  - **The Governance** (Constitution, Federation, Treaties)
  - **The Economy** (Wallet, Marketplace, BTO)
  - **The Evolution** (Improvement Log, Proposals, Impact)

## 3. Context-Aware Pathways
- Viewing a node in the Explorer should surface its **Economic Contribution** and **Treaty Status**.
- Participating in a **Constitutional Vote** should reflect immediate **Resonance Changes** in the Wallet.
- Proposing an **Enhancement** should trigger a **Cognitive Analysis** from the CEO Chat.

## 4. Integration Logic
- Use a central `AppRouter` that manages seamless transitions between civilizational layers.
- Implement the "Civilization Assistant" as a persistent floating node for cross-module guidance.

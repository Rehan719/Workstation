## 🚀 One-Click Global Launch
To initialize the consolidated vFinal stack across all platforms, run:

### Windows (PowerShell)
```powershell
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
.\setup.ps1
```

### macOS / Linux
```bash
chmod +x setup.sh && ./setup.sh
```

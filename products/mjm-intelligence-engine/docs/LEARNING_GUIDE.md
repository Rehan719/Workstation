# Learning & Evolution Guide

MJM is a living system that improves through its experiences.

## The Learning Loop
1. **Mushahida:** Sensory input is ingested.
2. **Jaiza:** Patterns are matched and risks evaluated.
3. **Muaina:** Actionable proposals are generated.
4. **Feedback:** Outcomes are ingested back into the Learning Engine.

## Adaptation Mechanics
- **Source Reliability:** The engine learns which sources provide the highest quality evidence and adjusts its attention profile automatically.
- **Pattern Effectiveness:** Successful analysis patterns are assigned higher confidence and propagated to compatible domains.
- **Strategic Evolution:** When performance thresholds are met, the engine proposes "genomic" updates via a governance workflow.

## Governance
Evolution is not uncontrolled. Every "genomic" update (change to a `.yaml` file or core rule) must be submitted as an Evolution Proposal and approved by a human or the AI CEO.
